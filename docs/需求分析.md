# 学科知识整合智能体 — 需求分析

## 1. 项目背景

在多教材教学场景中，学生需要同时参考多本教材学习同一学科。不同教材对同一知识点的表述、深度、侧重点各异，导致学生学习效率低、知识碎片化。本项目旨在构建一个学科知识整合智能体，通过AI技术实现跨教材知识自动整合、可视化和智能问答。

## 2. 用户角色

| 角色 | 描述 | 核心需求 |
|------|------|----------|
| 学生 | 使用多本教材学习的学生 | 快速理解跨教材知识点、精准问答 |
| 教师 | 编写教案、整合教材的教师 | 审阅整合方案、修改知识点、备课 |

## 3. 功能需求

### 3.1 教材加载解析
- 支持PDF、Markdown、TXT、DOCX四种格式
- 自动识别章节结构，统一为结构化JSON
- 支持拖拽上传、批量上传

### 3.2 知识图谱构建
- LLM自动提取每章节知识点（概念/定理/方法/现象）
- 构建知识图谱（节点=知识点，边=关系）
- 支持按类型/教材来源区分颜色
- 支持缩放、拖拽、搜索、节点详情查看

### 3.3 跨教材知识整合
- 语义对齐：Embedding相似度 + LLM判断
- 整合决策：merge/keep/remove
- 压缩比 ≤ 30%
- 教师可审阅和修改决策

### 3.4 RAG精准问答
- 分块策略：500-800字，50-100字重叠
- 嵌入模型：BGE-small-zh
- 向量检索：FAISS top-5
- 生成回答带引用来源（教材名、章节、页码）
- 支持SSE流式输出

### 3.5 教师多轮对话
- 审阅整合方案
- 自然语言修改知识点
- 系统自动调整决策
- 知识图谱实时更新

### 3.6 竞学堂对抗学习
- **学生模式**：8轮递进选择题，2位虚拟对手同时作答，RAG评判，积分+连胜系统
- **教师备课模式**：虚拟学生抛出典型误解，教师回应，多轮追问
- 虚拟对手有固定人格和不同说话风格
- 嘲讽强度随连续答错升级

## 4. 非功能需求

- 响应时间：问答延迟 < 3秒
- 并发支持：单用户场景
- 数据安全：教材文件本地存储
- 可扩展性：支持后续添加更多教材格式和LLM后端

## 5. 数据流

```
教材文件 → 解析器 → 章节JSON → LLM提取 → 知识点 → 图谱构建
                                              ↓
                                     Embedding → FAISS索引
                                              ↓
用户提问 → Embedding → FAISS检索 → LLM生成(带引用) → 回答
````
