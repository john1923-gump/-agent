## 4. 重点案例分析

### 案例1：细胞膜 vs 细胞质膜

**原始状态**：
- 教材A知识点："细胞膜是包围细胞质的薄膜，由磷脂双分子层和蛋白质组成，具有流动性和选择透过性"
- 教材B知识点："细胞质膜又称质膜，是细胞与外界环境的边界，控制物质进出"

**相似度**：0.92（Jaccard系数 + LLM确认）

**决策**：Merge

**合并后内容**：
> 细胞膜（又称细胞质膜/质膜）是包围细胞质的薄膜，由磷脂双分子层和蛋白质组成，具有流动性和选择透过性，是细胞与外界环境的边界，控制物质进出。

**分析**：
- 两个知识点描述同一概念，只是命名和侧重点不同
- 教材A侧重结构组成，教材B侧重功能
- 合并后信息更完整，保留了结构和功能两方面

### 案例2：主动运输 vs 被动运输

**原始状态**：
- 教材A知识点："被动运输是物质从高浓度向低浓度扩散，不需要能量"
- 教材B知识点："被动运输包括简单扩散和协助扩散，顺浓度梯度进行"
- 教材A知识点："主动运输是逆浓度梯度运输，需要载体蛋白和ATP"
- 教材B知识点："主动运输消耗能量，可维持细胞内外浓度差"

**相似度**：0.88（每对）

**决策**：Merge（分别合并）

**合并后内容**：
> **被动运输**：物质从高浓度向低浓度扩散，顺浓度梯度进行，包括简单扩散和协助扩散，不需要能量。
>
> **主动运输**：逆浓度梯度运输，需要载体蛋白和ATP能量，可维持细胞内外浓度差。

**分析**：
- 两本教材对运输方式的分类一致，但细节互补
- 合并后定义更完整，既有分类又有机制
- 保持了概念间的对比关系

### 案例3：ATP与能量代谢

**原始状态**：
- 教材A知识点："ATP是细胞的直接能源物质，由腺苷和三个磷酸基团组成"
- 教材A知识点："细胞呼吸分解有机物释放能量，合成ATP"
- 教材B知识点："ATP水解提供能量驱动细胞各种生命活动"

**相似度**：0.85（跨教材）

**决策**：Merge + Enrich

**合并后内容**：
> **ATP（腺苷三磷酸）**：细胞的直接能源物质，由腺苷和三个磷酸基团组成。通过细胞呼吸分解有机物合成，水解时释放能量驱动细胞各种生命活动。

**分析**：
- 三处描述构成ATP知识的完整图景：结构、合成、功能
- 合并后形成闭环：有机物 → 细胞呼吸 → ATP → 生命活动
- 体现了知识的内在联系
