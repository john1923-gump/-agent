## 2. 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端框架 | React 18 + TypeScript | UI构建 |
| 样式 | Tailwind CSS | 快速样式开发 |
| 状态管理 | Zustand | 轻量级状态管理 |
| 图谱可视化 | ECharts | 知识图谱力导向图 |
| HTTP客户端 | Axios + Fetch SSE | API通信和流式输出 |
| 后端框架 | FastAPI | 高性能异步API |
| LLM | OpenAI-compatible API | 知识提取、问答、评判 |
| 嵌入模型 | sentence-transformers (BGE-small-zh) | 中文文本嵌入 |
| 向量库 | FAISS | 向量相似度检索 |
| 文档解析 | PyMuPDF + python-docx | PDF/DOCX解析 |

## 3. 核心数据模型

### 3.1 教材相关
```
TextbookMeta: {id, filename, format, chapter_count}
Chapter: {id, textbook_id, textbook_name, title, content, page_start, page_end}
KnowledgePoint: {id, chapter_id, textbook_id, name, description, type, page}
Chunk: {id, textbook_id, chapter_id, content, page, embedding}
```

### 3.2 图谱相关
```
GraphNode: {id, label, type, textbook_id, frequency, size}
GraphEdge: {source, target, relation, weight}
KnowledgeGraph: {nodes[], edges[]}
```

### 3.3 整合相关
```
IntegrationPair: {kp_a, kp_b, similarity, decision, reason, merged_content}
IntegrationResult: {pairs[], compression_ratio, original_count, final_count}
```

### 3.4 竞学堂相关
```
ArenaOpponent: {id, name, personality, style}
ArenaQuestion: {id, question, options[], correct_answer, explanation}
ArenaRound: {round_num, question, opponent_answers, user_answer, is_correct, feedback}
ArenaSession: {id, mode, rounds[], score, streak, weak_points[]}
```

## 4. API设计

### 教材管理
- `POST /api/textbooks/upload` — 上传教材
- `GET /api/textbooks/list` — 列表
- `DELETE /api/textbooks/{id}` — 删除

### 知识图谱
- `GET /api/knowledge/graph` — 获取图谱
- `GET /api/knowledge/points` — 获取知识点列表
- `POST /api/knowledge/integrate` — 执行整合分析
- `POST /api/knowledge/integrate/apply` — 应用整合方案

### 智能问答
- `POST /api/qa/ask` — 普通问答
- `POST /api/qa/ask/stream` — SSE流式问答
- `POST /api/qa/teacher-chat` — 教师对话

### 竞学堂
- `GET /api/arena/opponents` — 获取对手列表
- `POST /api/arena/start` — 开始对局
- `POST /api/arena/answer` — 提交答案

## 5. RAG流程

```
用户提问
   ↓
Embedding (BGE-small-zh)
   ↓
FAISS Top-5 检索
   ↓
拼接上下文 + 引用来源
   ↓
LLM生成回答
   ↓
返回answer + references[]
```

## 6. 知识整合流程

```
所有知识点
   ↓
快速相似度筛选 (字符集Jaccard)
   ↓
Top-20 相似对
   ↓
LLM逐一判断: merge/keep/remove
   ↓
生成 IntegrationResult
   ↓
教师审阅 → 自然语言修改
   ↓
应用到图谱
```
